# File Organizer 📂

A Python automation script that automatically organizes files into folders by file type.

##  What It Does

This script scans any folder (default: Downloads) and sorts files into organized folders:

| Folder | File Types |
|--------|------------|
|  Images | .jpg, .png, .gif, .bmp, .svg |
|  Documents | .pdf, .docx, .txt, .xlsx, .csv |
|  Music | .mp3, .wav, .aac, .flac |
|  Videos | .mp4, .mov, .avi, .mkv |
|  Archives | .zip, .rar, .7z, .tar |
|  Code | .py, .cpp, .java, .js, .html, .json |
|  Applications | .exe, .msi, .dmg |

## 🔧 How to Use

### Method : Run Python script directly
```bash
python3 file_organizer.py
